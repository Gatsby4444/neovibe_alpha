## 3. Difficultés rencontrées ou erreurs commises

- **Un script Python passé en heredoc bash a été refusé** (« unexpected EOF
  while looking for matching `'` ») sans rien écrire ; repassé par un fichier
  dans le scratchpad. Rien de cassé, mais vérifier `git status` après chaque
  script — c'est ce qui a montré qu'il n'avait pas tourné.
- **Un script de réécriture a emporté deux widgets voisins** (`_FlashControl`,
  `_ColorButton`) en supprimant `_RecapStep` → `_Shot` : ils étaient rangés
  *entre* les deux dans le fichier. Vu à `flutter analyze`, restaurés depuis
  `git show HEAD:`. Leçon : quand on coupe « de A à B » dans un fichier, lister
  d'abord ce qui vit entre A et B (`grep -n "^class "`), pas seulement A et B.
- **Le heredoc bash mange les `\n` d'un script Python** (`'---\n\n## 3'`
  est arrivé avec de vrais retours à la ligne) : deux tentatives perdues sur le
  plan. Passer les scripts par un fichier écrit avec l'outil d'édition, pas
  par un heredoc.
- **GitHub 500 en boucle sur les releases** (voir 2.3). Leçon : lire l'état
  réel après chaque 500 (`gh api …/releases`) au lieu de réessayer — les
  écritures passaient, seule la réponse échouait ; trois tentatives ont fait
  trois brouillons.

- Un remplacement Python sur `diagnostic_bundle.dart` a échoué (0 occurrence)
  sur une chaîne contenant `\n` littéral et des accents ; refait avec l'outil
  d'édition direct. Rien de cassé — l'assertion a empêché toute écriture.
- Les résultats des tests JVM ne sont pas sous `android/app/build/` mais sous
